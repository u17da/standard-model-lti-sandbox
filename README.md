# 相互運用性標準モデル LTI接続テスト環境
## Standard Model LTI Sandbox

本プロジェクトは、日本の「相互運用性標準モデル」に基づいた LTI 1.3 接続の動作検証を行うためのサンドボックス環境です。

LTI 1.3 Advantage の仕様に加え、日本の教育現場で求められるサイレントログイン（`prompt=none`）や特定のユーザー属性（教員・児童生徒・学年等）の連携をシミュレートし、ツール開発者が迅速かつ正確に接続テストを行えるようにすることを目的としています。

## 主な機能
- **LTI Platform シミュレータ**: `iss`, `aud`, `sub` や LTI Claims を標準モデルに準拠して生成し、ツールへ送信します。
- **診断ツール (JWKS Check)**: ツール側が提供する公開鍵（JWKS）が正しく取得可能か検証します。
- **意図的なエラー生成**: `prompt` や `scope` の異常値を送信し、ツール側のバリデーションが正しく機能するか確認できます。
- **サンプルツール内蔵**: 接続を受ける側のツールの実装例として、そのまま動作確認に使用できます。

## 使い方（クイックスタート）

本システムはクラウド上にデプロイされており、セットアップ不要ですぐにご利用いただけます。

1. **アクセス**: [LTI接続テスト環境](https://standard-model-lti-sandbox.ecube.jp/)
2. **接続設定**: 開発中のツールのエンドポイントを入力します。
   - サンプルツールで試す場合は、画面内の「デモ用設定値を自動入力」をクリックしてください。
3. **テストの開始**: 「ツールを起動」をクリックすると、別ウィンドウで LTI 接続シークエンスが開始されます。

## ローカルでの開発・実行

開発者の方は、リポジトリをクローンしてローカル環境で実行することも可能です。

### 1. 起動
```bash
npm install
node server.js
```
デフォルトで `http://localhost:4000` で起動します。

### 2. 設定
ローカルで実行する場合でも、クラウド版と同様の機能が利用可能です。詳細は [USAGE_GUIDE.md](./docs/USAGE_GUIDE.md) を参照してください。
